# 多人旅游注意事项

## 行前共识
- **预算**：总上限+每日分项，预交300-500元公用金
- **节奏**：早起党vs懒觉党，找最大公约数
- **决策**：投票/轮流/领队，每天留1-2小时独处

## 分工建议
| 角色 | 职责 |
|------|------|
| 财务 | 记账收款，每日结算 |
| 导航 | 查路线叫车 |
| 美食 | 找餐厅点菜 |
| 摄影 | 规划机位修图 |

## 住宿&行程
- 情侣+单身：订两间房
- 集合：精确到分钟地标，迟到5分钟请奶茶
- 拍照：每人3-5张，发圈前询问

## 餐饮&钱
- 点菜：人数+2，忌口提前说
- 当场转账，不"回去再算"

## 冲突处理
- 想去不同地方：上午分头，午餐汇合
- 约定"暂停"暗号，小事不过夜

> 💡 事前多啰嗦，事中少生气
